# SemSync — Student Workspace

SemSync is a responsive, dark-mode semester planner built with HTML, CSS, and vanilla JavaScript. It helps students organize assignments, syllabus topics, subjects, and test marks in one place.

## Features
- Overview dashboard with task and syllabus progress
- Add, search, filter, complete, and delete assignments
- Track syllabus topics as Not Started, In Progress, or Completed
- Manage semester subjects and optional subject codes
- Save assessment scores and calculate percentages
- Browser local storage persistence
- Responsive layout for desktop and mobile
- No framework, build tools, backend, or paid services required

## Data and privacy
SemSync stores data in the browser's local storage on the device and browser being used. Data does not sync between devices and can be cleared by clearing browser site data. Do not enter sensitive personal information.
